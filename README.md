# Muhammad Bilawal — Behavioral Health RCM Portfolio

## Deploy
Upload the ZIP contents directly to the GitHub repository root. In Settings → Pages, select GitHub Actions.

## Search engine setup
1. Google Search Console: add the URL-prefix property `https://bilawal-1.github.io/portfolio1/`, use HTML tag verification, paste the issued meta tag in `index.html`, then submit `sitemap.xml`.
2. Bing Webmaster Tools: import the verified Google Search Console property, or add the issued Bing verification meta tag, then submit `sitemap.xml`.
3. Verify these URLs after deployment: `/robots.txt`, `/sitemap.xml`, `/favicon.ico?v=5`.
4. Search indexing is not instant. New GitHub Pages sites commonly need days or weeks to appear for competitive terms.

## Security
Never upload PHI, patient screenshots, claim numbers, payer credentials, client reports or confidential data.
